Sobre nós

AERIS é um projeto acadêmico de monitoramento ambiental desenvolvido por estudantes de Ciência da Computação. Nosso propósito é aproximar tecnologia e compreensão do ambiente, organizando medições para apoiar a observação das condições locais.

A proposta conecta sensores a um ESP32, que envia as medições para uma API e permite sua consulta na plataforma. O trabalho reúne coleta de dados, desenvolvimento web e análise ambiental como exercício de aprendizagem. A disponibilidade de leituras depende das estações.
